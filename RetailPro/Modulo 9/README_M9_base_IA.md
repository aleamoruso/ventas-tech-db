# RetailPro

Proyecto de análisis de datos para RetailPro, una empresa distribuidora de tecnología.

## Descripción

Este proyecto analiza los datos de ventas de RetailPro utilizando SQL para la base de datos y Power BI para la visualización.

## Herramientas utilizadas

- SQL
- Power BI
- Excel
- Git / GitHub

## Estructura del repositorio

- Scripts SQL para la creación de la base de datos y las consultas.
- Archivos de Power BI con los reportes y dashboards.

## Cómo ejecutar los scripts

1. Cloná el repositorio.
2. Abrí los scripts SQL en tu gestor de base de datos.
3. Ejecutá los scripts para crear la base de datos y correr las consultas.
4. Abrí los archivos .pbix en Power BI Desktop para ver los reportes.
